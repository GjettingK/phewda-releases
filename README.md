# PhewDA releases

Installers for PhewDA, a qualitative data analysis app, and the files PhewDA on
Windows reads to keep itself up to date. There is no source code here.

Download the newest version from [Releases](../../releases/latest):

- **Windows:** `PhewDA-Setup-….exe`. The installer is not signed, so Windows says
  *Windows protected your PC* the first time: choose **More info → Run anyway**.
  After that, PhewDA updates itself.
- **Mac (Apple Silicon):** `PhewDA-….dmg`. A Mac does not update itself: download
  the newer `.dmg` when there is one.

PhewDA on Windows asks this page for the newest version when it starts and every few
hours, and sends nothing about the person using it or their projects.
